# TMDB Film API_KEY

## 📌 Project Overview

Project ini bertujuan untuk mengambil dan menganalisis data film
menggunakan TMDB API, Python, dan Pandas.

Data film yang dikumpulkan berasal dari beberapa genre:
- Horror
- Action
- Adventure

## 🛠️ Tools & Technologies

- Python
- Pandas
- TMDB API
- Jupyter Notebook
- Git & GitHub

## 📊 Data yang Dikumpulkan

Beberapa informasi film yang dikumpulkan:

- Judul film
- Genre
- Bahasa
- Tanggal rilis
- Rating
- Popularity

## 🔄 Data Collection

Data diambil menggunakan TMDB API dengan beberapa parameter,
kemudian diubah menjadi Pandas DataFrame.

Prosesnya:

1. Mengambil data dari TMDB API
2. Menggabungkan data dari beberapa halaman
3. Menggabungkan data beberapa genre
4. Mengubah genre ID menjadi nama genre
5. Melakukan data cleaning
